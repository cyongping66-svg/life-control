# MVP 产品范围

## 目标用户与核心任务

面向希望减少生活信息分散、需要问题解答和轻量规划的个人用户。首版验证：

1. 用户能否因“回答附可靠来源”而信任并持续提问；
2. 用户能否持续维护财务、职业、社交三类事项；
3. 提醒是否能帮助用户完成一次实际行动。

## 首版能力

- 微信登录、开发环境体验登录；
- 问答历史、问题分类、官方资料检索、来源卡片和内容举报；
- 财务：银行卡、支付账号、贷款、信用事项的非敏感元数据；
- 职业：目标、副业、简历文件及版本；
- 社交：联系人、班级/关系、加密联系方式、生日、照片；
- 应用内提醒和经用户逐次授权的微信订阅消息；
- 管理端查看已核验来源与用户举报。

## 明确不做

- 不保存密码、验证码、完整银行卡号或身份证件；
- 不代替银行、政府、医生、律师或持牌财务顾问作决定；
- 不自动读取通讯录、相册或金融账户；
- 不抓取、搬运或缓存抖音和小红书的正文、图片、视频；
- 不根据互动量自动断言内容真实；
- 不自行训练基础大模型，也不在 MVP 阶段拆分微服务。

## 验收场景

- 输入“社保和公积金怎么查”，回答附人社部、住建部等已核验入口；
- 两个用户无法查看、修改或删除彼此的数据；
- API 拒绝包含非白名单字段的财务请求，界面不提供完整卡号输入；
- 联系方式在数据库中不是明文；
- 简历和照片只能通过短时签名地址访问；
- 未授权微信订阅消息时，提醒自动降级为应用内提醒。
