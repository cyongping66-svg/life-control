# 安全与隐私设计

## 数据分级

- 高敏感凭据：支付密码、验证码、完整卡号、私钥。禁止采集和存储。
- 敏感个人信息：手机号、简历、联系人照片。手机号使用 AES-256-GCM 字段级加密；文件放入私有对象存储。
- 一般个人信息：事项标题、卡片尾号、生日、职业目标。按用户隔离并受鉴权保护。
- 公共元数据：官方链接、公开作者和发布时间。保留核验时间和来源 URL。

## 控制措施

- 生产环境强制配置至少 32 字符 JWT 密钥和独立的 32 字节 Base64 字段加密密钥。
- API 使用白名单 DTO，额外字段直接拒绝；所有更新和删除都验证资源归属。
- 日志不得记录 Authorization、微信 secret、手机号明文、签名 URL 或模型 API key。
- 上传地址五分钟过期，下载地址一分钟过期；对象存储 bucket 必须保持私有。
- 删除联系人会同时删除数据库引用。对象实体清理应由部署环境配置生命周期规则，正式上线前需补充用户账户整体删除任务。
- AI 仅接收当前问题和公开来源，不接收联系人手机号、照片或完整个人档案。

## 外部内容

只保存链接、必要元数据和自有摘要。缩略图必须取得平台允许，不默认盗链。抖音、小红书等平台只在有官方开放能力或合规数据协议后接入；用户点击时回到原平台。

## 上线前置条件

- 完成微信小程序备案、主体与服务类目审核；
- 提供隐私政策、用户协议、账户注销和数据导出/删除入口；
- 完成依赖漏洞扫描、权限隔离集成测试和对象存储策略复核；
- 根据实际部署地确认个人信息保护法、数据出境和留存要求。
