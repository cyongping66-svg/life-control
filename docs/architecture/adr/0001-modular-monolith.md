# ADR-0001：微信小程序优先的模块化单体

- 状态：已接受
- 日期：2026-08-20

## 背景

项目处于从零验证阶段，同时包含问答、财务、职业、社交和提醒。直接采用微服务会增加部署、数据一致性和调试成本，但代码仍需为后续演进保留边界。

## 决策

- 客户端采用 Taro、React 和 TypeScript，首发微信小程序。
- 后端采用 NestJS 模块化单体与 PostgreSQL。
- AI 通过 `ModelProvider` 接口接入，首版可使用外部模型，不自行训练模型。
- 外部内容通过来源适配层进入系统；首版只接人工核验官方链接和合法开放接口。
- 重要规则由测试、接口契约、数据库迁移和 CI 保护，不把文档或契约设为不可修改。

## 影响

首版只有一个后端部署单元，交付与本地开发更简单。模块若被证明需要独立扩缩容，可在保持契约兼容的前提下提取为服务。
